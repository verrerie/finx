# Prompt Templates

This directory contains reusable prompt templates for common actions. You can copy the content of these files into your chat to quickly perform tasks.

## How to Use

1.  Find the template for the action you want to perform.
2.  Copy the content of the `.md` file.
3.  Paste it into the chat.
4.  Replace the bracketed placeholders `[like this]` with your own information.
